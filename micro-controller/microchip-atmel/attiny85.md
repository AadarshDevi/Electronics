# ATTiny85

## Setup
1. Add JSON Lib
```
https://raw.githubusercontent.com/damellis/attiny/ide-1.6.x-boards-manager/package_damellis_attiny_index.json
```
2. Install Board Library: Board Manager > Search "attiny" by David A. Mellis
3. Completely Close Arduino IDE
4. Open Arduino IDE

## Parts
1. ATTiny85-20PU
2. Jumper Wires
3. Breadboard

## Connection

### CP2102 USB to TTL Adaptor Programmer
| USB | ATTiny85 | Wire |
|:---:|:---:|:---:|
| 3V3 | VCC | Light Brown/Red |
| GND | GND | Black |
| RX | Pin 7 | Orange |
| TX | Pin 3 | Yellow |
